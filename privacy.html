Privacy policy

Ninety's Studios Publisher · Last updated 18 November 2026

Ninety's Studios Publisher ("the app") is a private tool that Ninety's Studios uses to publish to and measure its own YouTube channel, @ninetysstudios. Only the owner of that channel signs in to it.

YouTube API Services

The app uses the YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the app accesses, and why

With the channel owner's permission, the app requests exactly three Google permissions:

  • Upload YouTube videos (youtube.upload): to upload and schedule Ninety's Studios' own Shorts.
  • View your YouTube account (youtube.readonly): to read the channel's own uploads list and each video's status, so it can confirm a video was published and avoid uploading the same video twice.
  • View YouTube Analytics reports (yt-analytics.readonly): to read the channel's own performance figures, such as views, watch time, likes, shares and subscriber changes per video.

The app can't edit or delete videos, post or read comments, manage monetisation, or access any other account. It doesn't access any information about viewers as individuals.

What is stored, and where

  • Sign-in credentials: the OAuth client details and the refresh token Google issues are stored only on the channel owner's own computer, in a private file only that user can read. They're never stored in a code repository, shared or sent anywhere except to Google to obtain access.
  • Publishing records: for each upload, the video's title, its YouTube ID and link, its scheduled time and the result, stored locally.
  • Analytics: summary figures for the channel's own videos, stored locally to compare how videos perform.

No data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Publishing records and analytics are kept while the channel owner keeps the app authorised. YouTube data is refreshed or deleted in line with YouTube's developer policies.
  • If access is revoked or the app is retired, the stored token is deleted at once, and stored YouTube data is deleted within 30 days.

How to revoke access

Go to your Google Account's Third-party apps & services page (also reachable via Google security settings), select "Ninety's Studios Publisher" and remove access. The app stops working immediately.

Changes and contact

Changes to this policy are published on this page with a new date. Questions: open an issue on this site's GitHub repository.
